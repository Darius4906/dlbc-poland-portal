# Deeper Life Bible Church Poland — Church Operations Portal

Unified web platform for DLBC Poland (Warsaw, Gliwice, Online, and Combined Services) supporting:
- Flexible Multi-Session & Multi-Location Attendance Tracking
- First-Timer & Invitee Follow-Up CRM
- Service & Ministering Roster Builder with Conflict Detection
- Members & Workers Admin Directory (with Alias Merging, Inline Editing & Safe Archiving/Deletion)
- 2026 Annual Vision, Quarterly Plan & Church Noticeboard

## Quick Start (Local Development)
```bash
npm install
npm run dev
```

## Free Hosting on GitHub Pages
1. Create a **Public** repository on GitHub named `dlbc-poland-portal`.
2. Upload all files in this folder to the repository.
3. Go to **Settings -> Pages -> Source** and select **GitHub Actions**.
4. GitHub Actions (`.github/workflows/deploy.yml`) will automatically build and publish your site.
